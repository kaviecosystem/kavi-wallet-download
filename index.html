How to install

  1. Tap Download APK above.
  2. Open the downloaded file. If Android asks, allow “Install unknown apps” for your browser.
  3. Tap Install, then open Kavi Wallet.
  4. Create a new wallet, or import an existing one.

⚠ Test rules — please read

  • Keep only a small amount — only what you can afford to lose.
  • Write down your recovery phrase and keep it offline. It is the only way to restore your wallet.
  • Install only from this page.
  • Found a bug? Send a screenshot.
  • Anything odd (app stuck, wrong balance, stuck transaction)? Move your funds out right away.
